# Herdr

My [Herdr](https://herdr.dev) config: a PR-focused layout, keybindings, and the custom mods it uses.
Works on Windows and macOS (Linux too).

## Usage

Windows (PowerShell):

```powershell
.\setup-herdr.ps1
```

macOS / Linux:

```sh
./setup-herdr.sh
```

This links the files below into `~/.config/herdr-app`, so edits in either place are the same
file and Herdr hot-reloads them. Re-running is safe; existing files are moved to `~/.config/herdr-app-backup/<timestamp>`.
On Windows, files are symlinked (needs Developer Mode or an elevated shell, otherwise they are
copied) and mod folders use junctions.

## What's here

| Path | What it is |
|---|---|
| `layouts/main-pr.json` | The main layout with PR/branch panels |
| `mods/branches` | Branch list with PR open/create and copy-name (`y`, cross-platform clipboard) |
| `mods/git-changes` | Changed files / diff panel |
| `mods/pane-cycle` | Backs the `ctrl-tab` / `ctrl-shift-tab` pane cycling |
| `mods/prs` | Pull request list |
| `mods/status-pr` | PR status in the status bar |
| `keys.json` | Keybindings |
| `settings.json` | Personal settings (zoom, font, appearance) |

Herdr's shipped layouts and mods are rewritten on every start, so they are deliberately not
stored here. The `.d.ts` / `jsconfig.json` files in each mod are regenerated by Herdr.

## macOS notes

- `alt-h/j/k/l` (pane focus) rely on Herdr's `option_as_alt` setting. The default `auto` handles
  US layouts; on others set it to `on` in Settings > Keyboard.
- `ctrl-v` pastes images into terminals; Cmd-based shortcuts are not bound here.
- `branches` mod copy uses `pbcopy`.
